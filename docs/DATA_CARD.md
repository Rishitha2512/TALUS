# TALUS data card — Phase A

## Scope and intended use

This card describes the datasets currently present in this repository and the
Phase A provenance audit. TALUS is an academic decision-support prototype. Its
current datasets do not establish performance or safety for any operating mine.
The synthetic records are suitable for software demonstrations, pipeline
exercises, and testing only; they are not field observations.

### Synthetic label-generation rule and circularity

The generator computes a risk score:

```text
score = 0.35 * (1.5 / max(0.4, FoS))
      + 0.30 * (deformation_rate_mm_day / 15)
      + 0.20 * (pore_pressure_kPa / 120)
      + 0.15 * (blast_intensity / 10 if recent_blasting else 0)
      + Normal(0, 0.08)
```

The four numeric labels are assigned at score thresholds `0.65`, `1.05`, and
`1.55`. The random noise is sampled when generating the data but is not retained
per record. `scripts/audit_synthetic_labels.py` recomputes the score without
noise and measures agreement with the stored labels; it does not estimate model
generalization.

For the current 1,200-row CSV, 1,200 records were audited and the noise-free rule
agrees with 90.4167% of stored labels (macro-F1 0.8557). All five direct
noise-free score inputs are also among the 14 model features. This is direct
target-construction overlap and makes the synthetic classifier benchmark
optimistic/circular. The results are generated in
`results/synthetic_label_audit.json` and `results/synthetic_label_audit_rows.csv`;
rerun `python scripts/audit_synthetic_labels.py` to reproduce them.

## Candidate public external source: NASA Global Landslide Catalog

- **Source:** [Data.gov catalog record](https://catalog.data.gov/dataset/global-landslide-catalog-export), maintained by NASA's Global Landslide Catalog.
- **What it contains:** a historical inventory of reported landslide events, including reported rainfall-triggered events and source citations. It is not a complete presence/absence survey, nor a database of mine-slope Factors of Safety or TALUS risk classes.
- **Licence:** the catalog export record describes terms and conditions, but an explicit open-data licence suitable for redistribution was not verified. TALUS does not package a copy and does not treat public availability as permission to redistribute.
- **Access status for this Phase A run:** the historical export URL returned HTTP 404 in the available environment. No NASA records were downloaded, cached, transformed, or used for model training/evaluation.
- **Biases and limits:** reported-event and media/source-coverage bias; heterogeneous event reporting; no defensible mapping from inventory records to mine-specific FoS labels; unsuitable as direct external classification truth for this model.
- **Loader:** `python scripts/download_nasa_glc.py` attempts the historical export, validates event-date and coordinate columns, and writes only after validation. If the export is unavailable or terms require user acceptance, it fails with an explicit message. It is not a way around access terms.

## Real versus synthetic evidence

**Real:** no external geotechnical validation records are presently bundled or used.
The NASA catalog is a candidate event inventory only; the attempted export was
unavailable and its redistribution terms remain unverified.

**Synthetic:** the telemetry, material-property samples, generated labels, and
existing model scores. No accuracy, AUC, Brier score, or sim-to-real gap on real
mine FoS/risk labels is reported by this Phase A audit. Such metrics require a
legally usable, labelled external case-history dataset with compatible variables
and an independently documented validation protocol.

## Reproducibility and tests

```powershell
python scripts/audit_synthetic_labels.py
pytest -q tests/test_phase_a_data.py
```

The unit tests cover the generating formula, exact threshold boundaries,
agreement and feature-overlap reporting, missing inputs, and NASA CSV
validation/download behavior. The NASA loader's network access itself is
environment-dependent and is not necessary for offline tests.
